## Mô tả (VI)

Tiểu hành tinh sáng nhất bầu trời, chiếm ~9% khối lượng cả vành đai chính; có lõi kim loại phân tầng như hành tinh thu nhỏ.

## Description (EN)

The brightest asteroid in the sky, ~9% of the main belt's mass; differentiated with a metallic core like a protoplanet.

## 描述 (ZH)

天空中最亮的小行星，约占主带总质量的9%；有分异的金属核，如同原行星。
