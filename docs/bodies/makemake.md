## Mô tả (VI)

Hành tinh lùn vành Kuiper thứ 2 về độ sáng, bề mặt methan băng đỏ; tên thần sáng tạo của người Rapa Nui.

## Description (EN)

2nd-brightest Kuiper dwarf planet, reddish methane-ice surface; named for the Rapa Nui creator god.
